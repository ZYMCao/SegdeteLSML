## 运行

在项目根目录执行：

```sh
backend/.venv/bin/python -m pytest backend/tests -q
backend/.venv/bin/python -m pytest backend/tests --collect-only -q
```

Web 用例需要允许监听 `127.0.0.1` 随机端口。CLI 子进程显式指定源码路径并断言导入文件位置，避免误测虚拟环境中的旧安装副本。处理线程夹具从 `load_settings()` 构造配置，避免手工维护另一份配置结构。

## 验证范围

- 调度规则采用具体时间例子作断言；曾临时改成“从命令到达时计时”和“从采集开始时计时”，对应测试均失败，随后恢复实现。
- 死锁、设备失败、命令洪峰、启动状态、Web 退出、结果保存和 MQTT 批量重复分发均先用测试复现，再修复。
- 真实权重测试使用合成图像，是集成冒烟验证，不评价识别精度。没有配置所指的权重时，该项明确报告跳过。
- 本轮未完成物理相机与真实 MQTT broker 联合验收：本机枚举相机数为 0，未连接生产 broker。网络重连、真实相机 SDK 阻塞耗时和生产响应时间仍需在目标设备验证。
- `setFrameRate` 的测试只覆盖现有命令接收/确认行为；当前相机管理器没有运行时帧率设置接口，不能据此认定硬件帧率已改变。
- 同步 SDK 抓图和推理仍不能被命令抢占；本轮消除的是等待/暂停/预热帧间的额外响应延迟。
